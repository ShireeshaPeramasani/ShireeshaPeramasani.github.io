# Interactive QA Portfolio

A GitHub Pages-ready, static HTML/CSS/JavaScript portfolio.

## Deploy
1. Unzip.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets/` directory to the root of your `shireeshaperamasani.github.io` repository.
3. Commit to your GitHub Pages publishing branch.
4. Open https://shireeshaperamasani.github.io/ and hard refresh.

## Features
- Responsive dark/light mode, smooth scroll, animated terminal-style hero, scroll reveals, interactive career timeline
- Filterable skills and expandable job descriptions
- Interactive banking validation demo and example QA test cases
- Working PDF resume download (bundled under assets/)
- Reduced-motion support and keyboard-friendly controls

## Notes
- The QA lab and test cases are educational demonstrations, not a live bank or employer project.
- Review resume and experience claims for accuracy before publishing.
- No API keys or backend required.
